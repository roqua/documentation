## First use

You will receive an e-mail from us with an activation link when you are invited
to help manage a RoQua project. When you click this link, you must choose a new
password. After that you are redirected to a screen where you can set up
[two-step verification](#two-step-verification).

:::note
At some organisations, authentication goes through the company's central login. In that case you do not set up a password or two-step verification with us.
:::

## Two-step verification

RoQua uses two-step verification, which means that after entering your
password you must enter a code from your smartphone. For two-step verification you need a mobile device with an
authenticator app such as [Google Authenticator](https://support.google.com/accounts/answer/1066447?hl=en)
or [1Password](https://1password.com/pricing/).
